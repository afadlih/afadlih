# Profile Repository Roadmap

## Current state

The repository is intentionally complete as a GitHub special profile system:

- one structured source of truth;
- one generated profile README;
- three selected projects with clear evidence levels;
- detailed case studies for private and public work;
- curated public repository activity;
- strict validation and a small workflow surface.

## Next improvements that add real value

1. Add sanitized product screenshots only after they are current, readable, and privacy-reviewed.
2. Attach reproducible test evidence to a specific source revision when a project can be safely demonstrated.
3. Replace the temporary portfolio domain if a permanent custom domain is adopted.
4. Add a durable professional email to the profile data when one is available.
5. Re-evaluate selected projects when a stronger public repository provides better evidence than the current mix.

These are evidence upgrades, not blockers for the repository architecture. Do not reintroduce website-export, automatic project discovery, activity heatmaps, decorative badge walls, or generated claims without inspectable proof.
