# Release Manifest — Special Profile v3

## Purpose

A focused, commit-ready GitHub special profile repository for `afadlih`. The package presents selected engineering work clearly without acting as a duplicate website CMS.

## Included outcomes

- concise GitHub-native profile README without a dense hero image;
- exactly three selected projects with truthful public/private labels;
- NDA-safe PT Pindad internship context and PKM-KC 2026 recognition;
- deep case studies and explicit verification boundaries;
- source-pinned evidence for the public AI Content Strategy project;
- JSON Schema coverage for profile, projects, proof, activity sources, and activity snapshots;
- focused two-workflow automation set with immutable action pins;
- Dependabot and documented repository hardening settings;
- safe PowerShell apply helper with dry-run, backup, validation, and rollback;
- no website-export or candidate-intake subsystem.

## Release gate

The package is releasable only when this command passes:

```bash
python scripts/portfolio_ci.py final-check
```

Optional future screenshots and test captures may strengthen individual case studies, but they must not be represented as existing evidence until reviewed and sanitized.
